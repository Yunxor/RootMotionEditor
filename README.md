# RootMotionEditor


## 快速开始
1. 在你的项目中的`Plugins`文件夹中克隆该仓库，或者下载发布包并解压到你的项目中的`Plugins`文件夹中。如果没有`Plugins`文件夹，请自行创建。

2. 如果下载的发布包不是Build版本，请重新编译你的项目。

## 构建包
你可以直接下载编译好的包去使用。Build压缩包里包含了编译好的dll等文件，无需再次编译。

## 未来
当前插件仅作为临时的骨骼修改工具，目前理论上不仅可以修改Root骨骼，还可以修改其它骨骼。

如果想要功能更强大的RootMotion编辑器，我推荐看看 [官方商城上的Root Motion Fix Tool插件 - 作者Attaku](https://www.fab.com/listings/2aba8225-dcf7-4425-b171-b11f17cafae7)，
目测该插件的功能应该较为完善，但我这里不保证具体的使用体验是否保真(因为我也没买过这个插件使用过(#^.^#))。

如果后续有精力（或者说有Token），将以下面的方向进行更新：

1. 一键修复滑步
2. AI动作间补
